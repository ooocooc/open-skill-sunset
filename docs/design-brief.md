# Result presentation brief

## Product task

Skill Sunset is a local, read-only diagnostic tool for developers with accumulated generic `AGENTS.md`, `CLAUDE.md`, and `SKILL.md` instructions. The report must feel trustworthy before it feels clever: high information density, explicit evidence, stable status colors, and no automatic deletion.

## Three presentation layers

1. Terminal summary for fast feedback and CI.
2. Portable single-file HTML report for review, filtering, screenshots, and sharing without a server.
3. Markdown, JSON, Codex prompt, Claude Code prompt, and rollback manifest for implementation workflows.

## System

- Canvas `#050606`; panels `#0d0f0f` and `#131616`; borders `#262a29`.
- Signal green `#75f0a3` is reserved for health and suggested actions.
- Amber is update, violet is demote, red is retire/high-risk, cyan is merge.
- System sans for interface; system monospace for paths, verdicts, and evidence labels.
- Responsive two-column findings become one column below 850px.
- Visible focus, non-color labels, reduced-motion support, and no remote assets.

## Do / do not

- Do make evidence and uncertainty visible beside every recommendation.
- Do keep the generated report fully offline and portable.
- Do distinguish health score from model-quality evaluation.
- Do not hide excluded domain Skills or imply they were audited.
- Do not provide an automatic delete action in the first release.
